# 字体版权与许可

本目录字体均为专有字体，不适用本项目的 LPPL 许可证。以下结论基于当前文件的版权、许可及嵌入信息。

| 字体 | 版权主体 | 许可说明 |
| --- | --- | --- |
| 宋体 SimSun、新宋体 NSimSun | 北京中易中标电子信息技术有限公司 | 按随附产品许可使用；允许受限文档嵌入，未授予独立再分发权。 |
| 黑体 SimHei、楷体 KaiTi、仿宋 FangSong | 北京中易中标电子信息技术有限公司 | 保留全部权利；未附完整许可文本，须核对产品协议或单独授权。 |
| 华文仿宋 STFangsong | 常州华文印刷新技术有限公司 | 保留全部权利；须核对随附应用的许可或单独授权。 |
| Times New Roman 常规、粗体 | Monotype；字体数据另涉及 Type Solutions | 内置许可限制为获许可工作站的出版用途；没有额外授权时，不得复制或分发字体软件。 |
| Times New Roman 斜体、粗斜体 | Monotype；字体数据另涉及 Type Solutions | 未附完整许可文本；`MS core font` 标签不能作为再分发授权凭证。 |

**文档嵌入权限不等于字体文件再分发权。** 中文字体标记为可编辑嵌入，Times New Roman 标记为可安装嵌入，均须遵守适用许可。当前未确认覆盖公开仓库、Release 分发或 Linux CI 安装的授权。

许可依据：[微软字体再分发说明](https://learn.microsoft.com/en-us/typography/fonts/font-faq)、[OpenType 嵌入权限](https://learn.microsoft.com/en-us/typography/opentype/spec/os2#fstype)、[Monotype 许可说明](https://www.monotype.com/font-licensing-explained-designers-and-brands)。
