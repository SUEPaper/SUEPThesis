# 学校原始 Word 文档

当前规范依据为本目录中用户提供的四份 `.doc` 原件。格式说明既包含正文，也包含 Word 文本框中的批注；阅读时应同时检查两者。

| 原件 | 用途 |
| --- | --- |
| [本科格式示范文本](上海电力大学本科生毕业设计（论文）格式示范文本.doc) | 本科正文、摘要、目录、图表、公式、文献及附录格式 |
| [本科封面](<上海电力大学毕业设计（论文）封面 .doc>) | 校名、论文类型、题目与个人信息栏 |
| [本科原创性及使用授权声明](上海电力大学毕业设计（论文）原创性及使用授权声明.doc) | 两份声明原文、签名与日期栏 |
| [硕士与博士范本](<上海电力大学硕士（博士）学位论文范本 （试行）.doc>) | 学术/专业硕博封面、扉页、声明、正文与后置部分 |

本科正文示范在本机 Word 中为 15 页，硕博范本为 26 页；分页会随 Word 版本、字体、打印环境和域更新而变化。目录中的页码也可能是原件保留的示例数据，不能作为模板实际页数的期望值。

`scripts/check_resources.py` 使用 Python 标准库检查四份原件的 Word 格式标识与 SHA-256。更新原件后，应先阅读新文件并记录规范变化，再更新检查中的摘要。构建与日常检查不要求安装 Word，也不要求把原件转换为其他格式。

当前验收使用原始 Word 规范、示例编译结果与数学字体字号检查；本科、硕士和博士统一采用 `unicode-math` 的要求优先执行。
